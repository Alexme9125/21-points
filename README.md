# 21点

1 到 6 名闲家对庄家的网页 21 点。规则按[百度百科·21点](https://baike.baidu.com/item/21点/5481683)。

## 本地开发

需要 Node.js 20+。

```bash
npm install
npm test
npm run dev
```

浏览器打开 http://127.0.0.1:5173 （Vite 会把 `/api` 和 `/ws` 代理到 8080）。

生产模式（单端口同时提供页面和 WebSocket）：

```bash
npm run build
npm start
```

默认监听 `8080`。

## Docker

```bash
docker compose up --build
```

打开 http://127.0.0.1:8080 。

## 玩法摘要

- 1–6 名闲家对庄家。2–10 按点数，J/Q/K 为 10，A 为 1 或 11。开局前可增减人数。
- 牌靴按人数自动选择：1 人 1 副，2–3 人 2 副，4–5 人 4 副，6 人 6 副。
- 开局 100K Tokens，每局最小 1K、最大 10K。可点 1K / 2K / 5K / 10K、续注，或自己输入金额。
- 要牌、停牌、加倍、同点分牌；庄家明牌不是 A 时可投降（收回一半）。
- 黑杰克（前两张 A+10 点牌）1 赔 2；普通赢局 1 赔 1；点数相同则平。分牌后的 21 不算黑杰克。
- 庄家 16 及以下必须要牌，17 及以上停牌。闲家爆牌即输，即使庄家随后也爆。
- 本桌不设保险。满 12 局结算本盘。

本游戏仅为计分娱乐，Tokens 不是真实货币。
