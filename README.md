# 21点

网页端 21 点纸牌游戏，支持 1 到 6 名闲家对一名庄家。可单机与 Bot 同桌，或用 6 位房间码与好友联机。规则参照[百度百科·21点](https://baike.baidu.com/item/21点/5481683)。

可在大厅选择 1 到 6 人座，开局前房主也可在等待房间内调整人数。人机模式自动由 Bot 补齐空位；联机房间满座后自动开局，房主也可提前用 Bot 补齐座位开局。内置 9 名不同下注与要牌风格的 Bot，思考时间在 3.6 到 12 秒之间。联机模式下玩家可在座位上改名；真人回合限时 30 秒（断线时为 8 秒），超时在下注阶段自动下最小注 1K，在行动阶段自动停牌。联机对局中若有真人离开，当前局终止并回到等待状态。

仓库采用 npm Workspaces 单仓结构，包含纯 TypeScript 规则引擎 `@hotpot/engine`（`packages/engine`）、Fastify 5 与 WebSocket 房间服务 `@hotpot/server`（`apps/server`）以及 React 19 + Vite 6 前端 `@hotpot/web`（`apps/web`）。房间与会话保存在服务端内存中，重启服务会清空进行中的牌局。

## 玩法与规则

牌靴副数按座位数自动配置，1 座用 1 副（52 张），2 到 3 座用 2 副，4 到 5 座用 4 副，6 座用 6 副。发牌前若剩余牌量低于牌靴总数的四分之一（或不足 20 张），自动重新洗牌。2 到 10 按牌面计点，J / Q / K 计 10 点，A 可计 1 点或 11 点。

每人初始 100K Tokens，单局下注范围为 1K 到 10K（步长 1K）。下注阶段可点选 1K / 2K / 5K / 10K 筹码、续注或续注翻倍，也可通过桌面端滑条与输入框填写金额（支持 `3000` 或 `3K` 格式）。

每人先下注再拿两张明牌，庄家发一张明牌与一张暗牌。轮到闲家时可选择要牌或停牌；超过 21 点即爆牌并直接输掉本手赌注，即使庄家随后也爆牌。首两张牌非黑杰克且筹码足够时可加倍（追加一倍赌注，只补一张牌后停牌）。拿到同牌面对子且筹码足够时，可追加一注分牌为两手独立结算（不可再次分牌；A 分牌后每手只补一张即停牌，分牌凑成的 21 点按普通 21 点 1 赔 1 结算）。庄家明牌非 A 时，未分牌的首两张手牌可选择投降并收回一半赌注。

若庄家首两张为黑杰克（A 配 10 点牌），当即开牌结算；否则所有闲家行动完毕后庄家亮出暗牌，16 点及以下必须要牌，17 点及以上（含软 17）停牌。闲家黑杰克 1 赔 2（返还本金加 2 倍彩金，若庄家同为黑杰克则平局返还本金），普通赢局 1 赔 1，点数相同为平局。牌桌不设保险。每满 12 局或全桌无人剩余至少 1K Tokens 时结算本盘盈亏，结算后可继续下一盘。局内 Tokens 仅作计分娱乐。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

启动后在浏览器打开 `http://127.0.0.1:5173`。Vite 开发服务器会将 `/api` 和 `/ws` 代理到本机 `8080` 端口。

## 构建与部署

构建前端与服务端后，由单个 Fastify 进程在同端口提供静态页面、HTTP 接口与 WebSocket 服务。

```bash
npm run build
npm start
```

服务默认监听 `0.0.0.0:8080`，可通过环境变量 `PORT` 和 `HOST` 修改监听端口与地址。

使用 Docker Compose 构建并启动容器。

```bash
docker compose up --build
```

容器启动后访问 `http://127.0.0.1:8080`。

## 测试与检查
